개인정보처리방침

최종 수정일: 2026년 11월 8일

utube-upload는 운영자가 소유하거나 관리 권한을 가진 YouTube 채널의 업로드 작업을 수행하는 개인용 데스크톱 도구입니다. 이 방침은 이 도구가 Google 및 YouTube 데이터를 처리하는 방식을 설명합니다.

1. 접근하는 정보

  • Google OAuth가 발급한 액세스 토큰과 갱신 토큰
  • 인증된 YouTube 채널의 식별자와 채널 정보
  • 운영자가 선택한 영상, 썸네일, 자막과 제목·설명·게시 시각 등 업로드 정보
  • 중복 업로드 확인 및 작업 검증에 필요한 영상 목록, 처리 상태, 공개 상태, 자막과 썸네일 확인 결과

앱은 Google 계정 비밀번호를 수집하지 않습니다. Google 동의 화면에서 요청하는 YouTube 접근 권한은 업로드와 관련 자료의 등록·확인에 사용합니다.

2. 이용 목적

이 정보는 연결된 채널 확인, 운영자가 지시한 영상 업로드·예약, 자막·썸네일·메타데이터 등록, 필요한 재생목록 작업, 중복 방지, 작업 재개와 결과 검증에 사용합니다. Google 사용자 데이터를 판매하거나 광고 타기팅에 사용하지 않습니다.

3. 저장과 보관

인증 토큰은 운영자 PC의 인증 전용 위치에 저장합니다. 작업 파일과 업로드 결과 기록은 운영자가 관리하는 로컬 작업 폴더에 보관합니다. 별도로 보관 작업을 지시한 경우 완성본과 결과 자료는 운영자가 선택한 Google Drive 등 보관 위치에도 저장될 수 있습니다. 인증 토큰은 이러한 제작 자료에 포함하지 않습니다.

운영자는 작업에 필요하지 않은 로컬 기록과 보관 파일을 삭제할 수 있습니다. Google 연결을 해제하더라도 이미 업로드된 영상이나 로컬 작업 파일이 자동으로 삭제되는 것은 아닙니다.

4. 정보 전달

앱 기능 실행에 필요한 파일과 요청은 Google OAuth 및 YouTube API로 전송합니다. 별도의 보관 작업을 선택했다면 지정한 저장 서비스에도 해당 자료를 전달합니다. 업로드한 영상의 공개 범위와 예약은 운영자가 지정한 YouTube 설정을 따릅니다.

이 안내 웹사이트에는 회원 가입, 결제 또는 파일 제출 기능이 없습니다. 호스팅 제공자는 서비스 운영과 보안을 위해 접속 로그를 처리할 수 있습니다.

5. 연결 해제와 삭제

Google 계정의 서드 파티 연결 관리에서 앱의 접근 권한을 철회할 수 있습니다. 로컬에 저장된 인증 파일과 작업 기록은 운영자 PC에서 별도로 삭제할 수 있습니다. 이미 게시한 영상은 YouTube Studio에서 관리할 수 있습니다.

정보 처리, 연결 해제 또는 삭제에 관한 문의: Google 계정 연결 시 동의 화면에 표시되는 앱 지원 이메일로 문의해 주세요.

6. 관련 서비스 안내

이 앱은 YouTube API 서비스를 사용합니다. 관련 서비스에는 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다. Google 사용자 데이터는 앱에 설명된 기능 제공 목적에 한해 사용합니다.

7. 방침 변경

앱 기능 또는 데이터 처리 방식이 변경되면 이 페이지를 수정하고 변경일을 표시합니다.
